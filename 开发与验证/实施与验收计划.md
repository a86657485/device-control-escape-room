# 机关密室：设备控制逃脱行动 Implementation Plan

**Goal:** 六年级学生通过控制设备、观察结果、收集线索完成密室逃脱；交付离线单文件 HTML 与可编辑教学设计。
**Architecture:** 原生 HTML/CSS/JavaScript 与内嵌 SVG。源码在本目录，构建后仅需打开上一级 index.html。学习过程本机保存，可导出记录；不需要网络和账户。
**Tech Stack:** 浏览器标准、Node 内置测试、Playwright、docx。动画使用 transform/opacity 并支持减少动态效果。

## 已批准范围
六区：光影入口、风力机关室、模式密码间、城市控制舱、时间锁档案室、出口。每个区域有分步操作、试运行反馈与解释性取证。教材表格转为记录；机械钥匙与智能门锁比较，展示进步但不暗示智能一定更安全。公共设备只在模拟界面操作。

## 视觉方案
夜蓝 #243750、薄荷 #65D5B3、雾白 #F1F5F8、琥珀 #F7C46B、淡紫 #B7AAF0。中文使用本机 PingFang SC，数字使用等宽字体。签名视觉为可互动的剖面机关房间、线索插槽和实体拨钮。大部分空间留给场景；右侧任务与控制面板。窄屏上下排列。

## 文件职责
- core.js：房间任务数据、控制条件、反馈、初始状态；可在 Node 中验证。
- app.js：页面生成、SVG、交互、保存、线索簿、报告与同伴机关卡。
- style.css：响应式布局、设备动画、打印与减少动态效果。
- build.cjs：将源码嵌入 index.html。
- core.test.cjs：验证各步正确/错误状态、认知检查及终局条件。
- browser-test.cjs：使用真实点击完成主线、错误路径、保存恢复、导出与移动端检查。
- make-docs.cjs：生成教学设计与学生任务单 DOCX。

## 验收标准
18 个操作任务、6 个解释检查；正确操作才能推进；每个区域奖励不重复；刷新恢复；本机保存不可用时明确提示；报告保留原始尝试和解释；无外网请求、无页面脚本错误；窄屏无横向溢出；键盘焦点可见；重开需页面内确认。内容覆盖教材三目标与表格，单课避免把输入计算输出/反馈等后续内容列为必达目标。25—30 分钟为教学设计估计，不宣称已由学生实测。
