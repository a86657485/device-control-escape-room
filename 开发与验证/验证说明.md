## 审查修正

独立代码审查发现并修复：城市动画未服从信号；修改机关后直接交接仍使用旧设置；补充说明清除同伴记录；密码数字键丢失焦点。新增浏览器回归检查覆盖这些问题。

美术PNG采用WebP编码压缩，解决大图片内嵌CSS变量的浏览器限制；最终单文件约1.2MB。动态机关包括风扇、叶轮、羽片、定时时钟、洗衣机与钥匙传送等。

## 实用边界

- 教师已带班使用旧版并反馈完成过快。本版据此修订；新的完成时间和学习成效尚待课堂复测，不以强制等待增加时长。
- 尚未从实际电脑教室学生设备验证跨设备网络访问，也未进行全班并发压力测试。
- Windows启动入口未在Windows系统双击实测；Safari、Edge未分别进行完整主线测试。
- 局域网服务不接收学生数据，进度和报告在学生各自浏览器；无教师端集中统计。
- 迁移拼句按设备与功能关系核对，并接受合理的同义搭配；开放项目记录由教师或同伴评价。
- 素材由内置image_gen生成，工具未公开模型名称，不能确认指定使用image2。

## 复现

安装 package.json 所列开发依赖后，运行 npm test、npm run build、npm run test:e2e。浏览器测试输出保存在本目录“浏览器验证”，该目录不纳入Git。

生成文档：npm run docs。PDF转换时必须确认中文字体可用。此制作环境为LibreOffice单次配置字体目录 /System/Library/Fonts 与 /System/Library/Fonts/Supplemental 后成功，不依赖修改系统字体设置。
